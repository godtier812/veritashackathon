**Second extra arm, added after the test run (exploratory):** `arm5` keeps `arm2`'s ESM-2 scores and changes only the cutoff: instead of catching at least 90% of harmful mutations, it takes the cutoff with the best catch rate minus false-alarm rate on `1–101`, frozen in `outputs/frozen_arm5.json` before one run on the end region (`outputs/results/arm5_run_log.txt`). It caught 220 of 267 harmful mutations (47 missed, vs 15 for `arm2`) with 136 of 899 false alarms (vs 437); 84.3% of calls were right vs 61.2% (difference `+23.1` points, 95% interval `+19.7` to `+27.1`). On the held-out region the balanced cutoff gave more correct calls than `arm2`. The ranking, and so the AUROC, is the same as `arm2`'s: this is a different trade between missed harmful mutations and false alarms, not a better model.
